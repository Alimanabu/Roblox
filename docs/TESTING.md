# ✅ Как проверить игру в Roblox Studio

Код писался без запуска в Studio: он проверен компилятором Luau, собран через Rojo,
игровая математика покрыта тестами (`tests/run.py`), дважды проведено ревью. Но вживую
игру никто ещё не запускал. Пройди этот список и пиши, что сломалось. Самое полезное:
**красные ошибки из окна Output** (View → Output).

## Подготовка
1. `rojo serve` в папке проекта, в Studio открыть Baseplate и нажать Connect в плагине Rojo.
2. Чтобы работали сохранения: Game Settings → Security → **Enable Studio Access to API Services**.
   Без этого игра тоже работает, но без сохранений (в Output будет предупреждение).

## Панель «🛠 Тест»
В Studio в меню слева есть кнопка **🛠 Тест**: выдать монеты и уровни, любого брейнрота,
мутанта, запустить любой ивент на 2 минуты, пропустить обучение, сбросить ежедневные
награды или весь прогресс. Так всё можно проверить без многочасового фарма.
В опубликованной игре панель видна только UserId из `src/shared/Config/Admins.luau`.

## Один игрок (кнопка Play)
- [ ] Появляешься на своей базе, вверху видны монеты ($150), уровень, удача, ивент.
- [ ] Внизу подсказка обучения «1/5», кнопка 🏭 Фабрика мигает.
- [ ] Фабрика → «Старый мем» → «Создать»: всплывает окно с 3D-брейнротом, слышен звук,
      на базе появляется брейнрот с лицом и аксессуарами, монеты начинают капать.
- [ ] Обучение проходит все 5 шагов. Шаг 4: голубая кнопка замка подсвечена, нажимается E.
- [ ] 🧠 База: продажа, «Продать всех», скрещивание 3 → 1.
- [ ] ⬆️ Улучшения покупаются, «Расширение базы» добавляет постамент.
- [ ] 📖 Индекс: открытые брейнроты в цвете, остальные чёрные силуэты.
- [ ] 🎁 Награды: забрать день 1, задания с прогрессом.
- [ ] ❓ Как играть открывается.
- [ ] Перезайти: прогресс сохранился, пришло «пока тебя не было...».

## Два игрока (Test → Clients and Servers → 2 Players → Start)
- [ ] Каждый получил свою базу, на табличке над базой имя.
- [ ] Первые 90 секунд база защищена (🛡️), чужак у забора выталкивается.
- [ ] Игрок 2 подходит к брейнроту игрока 1 и зажимает **F**. Брейнрот над головой,
      игрок 2 подсвечен красным и медленный, у игрока 1 сирена и сообщение.
- [ ] Игрок 2 добегает до своей базы: брейнрот переехал к нему.
- [ ] Игрок 1 шлёпает вора Шлёпалкой (клавиша 1, клик): вор отлетает, брейнрот возвращается.
- [ ] Замок на 60 с, потом перезарядка 30 с (⏳).
- [ ] Пока у тебя крадут, перерождение не даёт нажать.

- [ ] Обмен: игрок 1 → 🤝 Обмен → «Предложить», у игрока 2 всплывает приглашение.
      Оба кладут брейнротов, жмут «Готов», через 3 с брейнроты поменялись местами.
      Если во время отсчёта поменять предложение, «Готов» снимается.

## Ивенты
- [ ] Справа плашка «Следующий ивент ... через ...». В :00/:15/:30/:45 начинается ивент,
      в :06–:07 каждого часа идёт МИНУТА 67.
