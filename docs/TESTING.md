# ✅ Как проверить игру в Roblox Studio

Код писался без запуска в Studio: он проверен компилятором Luau, собран через Rojo,
игровая математика покрыта тестами (`tests/run.py`), дважды проведено ревью. Но вживую
игру никто ещё не запускал. Пройди этот список и пиши, что сломалось. Самое полезное:
**красные ошибки из окна Output** (View → Output).

## Подготовка
1. `rojo serve` в папке проекта, в Studio открыть Baseplate и нажать Connect в плагине Rojo.
2. Чтобы работали сохранения: Game Settings → Security → **Enable Studio Access to API Services**.
   Без этого игра тоже работает, но без сохранений (в Output будет предупреждение).

## Панель «🛠 Тест»
В Studio в меню слева есть кнопка **🛠 Тест**: выдать монеты и уровни, любого брейнрота,
мутанта, запустить любой ивент на 2 минуты, пропустить обучение, сбросить ежедневные
награды или весь прогресс. Так всё можно проверить без многочасового фарма.
В опубликованной игре панель видна только UserId из `src/shared/Config/Admins.luau`.

## Один игрок (кнопка Play)
- [ ] Появляешься на своей базе, вверху видны монеты ($150), уровень, удача, ивент.
- [ ] Внизу подсказка обучения «1/5», кнопка 🏭 Фабрика мигает.
- [ ] Фабрика → «Старый мем» → «Создать»: всплывает окно с 3D-брейнротом, слышен звук,
      на базе появляется брейнрот с лицом и аксессуарами, монеты начинают капать.
- [ ] Обучение проходит все 5 шагов. Шаг 4: голубая кнопка замка подсвечена, нажимается E.
- [ ] 🧠 База: продажа, «Продать всех», скрещивание 3 → 1.
- [ ] ⬆️ Улучшения покупаются.
- [ ] 🏗 Этажи: в начале 5 мест на земле, рядом жёлтый «призрак» 1 этажа и жёлтая табличка
      «🏗 1 этаж: $100K». Выдай монеты (🛠 Тест), подойди к табличке и зажми E: появился
      мраморный пол, мест стало 10. Затем 2 этаж за $100M: колонны, пол наверху, пандус справа,
      стеклянные перила. Сильнейшие брейнроты переехали наверх, у них «⭐ 2 этаж» в 🧠 Базе
      и доход x2. Кнопка «Построить» есть и в ⬆️ Улучшениях и 🧠 Базе.
- [ ] Поднимись по пандусу: перила не дают упасть, с пандуса на этаж проход есть.
- [ ] 🛠 Тест → «🏗 Снести этажи»: снова земля и 5 мест.
- [ ] 📖 Индекс: открытые брейнроты в цвете, остальные чёрные силуэты.
- [ ] 🎁 Награды: забрать день 1, задания с прогрессом.
- [ ] ❓ Как играть открывается.
- [ ] ⚙️ (рядом с уровнем): переключатели музыки, звуков и объявлений работают и сохраняются.
- [ ] 🎁 Награды → 🎡 «Крутить колесо (бесплатно!)»: призы мелькают и останавливаются,
      приходит награда. Второй раз за день бесплатно крутить нельзя.
- [ ] 🎁 Награды → ⏰ подарки за игру: через 5 минут первый можно забрать.
- [ ] 🎁 Награды → поле промокода: `SIXSEVEN`, `BRAINROT`, `RIZZ`, `SKIN67`. Повторно не принимает.
- [ ] 🏆 Достижения: после первого крафта «Первый брейнрот» получено.
- [ ] 🎨 Скины: купить «Огненный» ($50K, выдай монеты через 🛠 Тест), выбрать и
      «Надеть» на брейнрота: на базе он горит.
- [ ] 🏭 Фабрика: на карточках «🎯 ... точно через N», число уменьшается с каждым крафтом.
- [ ] 🛠 Тест → «🎃 Сезон Хэллоуин»: в Фабрике первой появилась Хэллоуинская капсула,
      из неё падают тыква, скелет, призрак, вампир. «Выключить сезон»: капсула пропала.
- [ ] ♻️ Перерождение и продажа Ауры и выше просят нажать второй раз.
- [ ] 🧠 База: строка бонусов (друзья / Premium / группа).
- [ ] Перезайти: прогресс сохранился, пришло «пока тебя не было...».

## Два игрока (Test → Clients and Servers → 2 Players → Start)
- [ ] Каждый получил свою базу, на табличке над базой имя.
- [ ] Первые 90 секунд база защищена (🛡️), чужак у забора выталкивается.
- [ ] Над брейнротом полоска ❤️ (на земле 5, на 1 этаже 10, на 2 этаже 20).
- [ ] Игрок 2 нажимает **F** у брейнрота игрока 1: «Сначала выбей ❤️». Берёт Шлёпалку (1)
      и шлёпает брейнрота: ❤️ убывает, у игрока 1 «⚠️ ... бьёт твоего ...».
      Бросил бить на 5 секунд: ❤️ восстанавливается.
- [ ] ❤️ кончилось: «💫 ОГЛУШЁН!», кнопка «Украсть!». Игрок 2 зажимает **F**. Брейнрот над головой,
      игрок 2 подсвечен красным и медленный, у игрока 1 сирена и сообщение.
- [ ] Через 15 секунд оглушение проходит, ❤️ снова полное.
- [ ] С земли нельзя шлёпнуть брейнрота на 2 этаже, надо подняться по пандусу.
- [ ] Игрок 2 добегает до своей базы: брейнрот переехал к нему.
- [ ] Игрок 1 шлёпает вора Шлёпалкой (клавиша 1, клик): вор отлетает, брейнрот возвращается.
- [ ] Замок на 60 с, потом перезарядка 30 с (⏳).
- [ ] Пока у тебя крадут, перерождение не даёт нажать.

- [ ] Обмен: игрок 1 → 🤝 Обмен → «Предложить», у игрока 2 всплывает приглашение.
      Оба кладут брейнротов, жмут «Готов», через 3 с брейнроты поменялись местами.
      Если во время отсчёта поменять предложение, «Готов» снимается.

- [ ] ⚔️ Баттлы: «🤖 Тренировка с ботом» показывает 3 раунда по очереди и итог.
      Вызов второго игрока: у него всплывает приглашение, после «Принять» бой у обоих.
- [ ] Ловушка: купи «Ловушка для воров», пусть второй игрок крадёт: он замирает,
      подсвечен жёлтым.
- [ ] Друзья: если игроки — друзья в Roblox, в 🧠 База видно «Друзья на сервере 1/4 (+10%)».

## Ивенты
- [ ] 🛠 Тест → «👹 Босс»: на площади огромный медведь с полоской здоровья, шлепки снимают
      здоровье, ударная волна отбрасывает, после победы награды и сообщение «Босс повержен».
- [ ] 🛠 Тест → «🤌 Минута 67»: диско-шар с лазерами над площадью, все брейнроты танцуют.
- [ ] 🛠 Тест → «Брейнрот Бог»: столб света в небо над базой, молнии, баннер и облёт камеры.
- [ ] 🛠 Тест → «🦎 Дикий брейнрот»: на карте бегает дикарь, зажми E рядом — он твой.
- [ ] 🧠 База → 🐾 у брейнрота: он бегает за тобой. Нажми на имя → дай имя, оно видно на базе.
- [ ] Справа плашка «Следующий ивент ... через ...». В :00/:15/:30/:45 начинается ивент,
      в :06–:07 каждого часа идёт МИНУТА 67.
